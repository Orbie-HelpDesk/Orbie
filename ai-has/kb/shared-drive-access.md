# Shared Drive and Folder Access

## Common problems
Cannot open the shared drive. Access denied to a folder. Network drive is missing. Cannot save a file to the team folder. Need access to another team's folder. Mapped drive disappeared.

## When to use
Employee cannot reach a shared drive or folder, or needs permission to use it.

## Steps
1. Check that you are connected to the company network or the VPN.
2. Restart the computer to refresh mapped drives, then try the folder again.
3. Confirm the path is correct by asking a teammate who can open it.
4. If you see "Access denied", you probably need permission. Submit an access request in the self-service portal with the folder name and your manager's name.
5. Wait for approval from the folder owner, then sign out and sign in again.

## Escalate if
Teammates can open the folder but you cannot after approval, the drive is missing for the whole team, or the folder owner is unknown.
