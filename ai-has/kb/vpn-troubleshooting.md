# VPN Troubleshooting

## Common problems
VPN is not working. VPN won't connect. Cannot connect to the company network from home. VPN keeps disconnecting. VPN error. Remote access is not working.

## Common fixes
1. Check internet connection first (open any website).
2. Restart the VPN client and reconnect.
3. Make sure the client is on the latest version.
4. Try a different server/region.
5. Disconnect other VPNs or proxies.

## Escalate if
Error persists after all steps, or error code mentions "certificate" or "authentication failed".
