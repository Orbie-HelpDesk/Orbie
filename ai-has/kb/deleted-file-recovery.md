# Recovering Deleted or Overwritten Files

## Common problems
I deleted a file by mistake. File is missing from the folder. I saved over the wrong version. Need to restore an old version of a document. Document closed without saving.

## When to use
Employee needs to get back a deleted, missing or overwritten file.

## Steps
1. Check the Recycle Bin on your computer and restore the file from there.
2. For files in OneDrive or SharePoint, open the web version and check its recycle bin, which keeps deleted files for a limited time.
3. To recover an older version of a document, open the file's version history and restore the version you need.
4. For an unsaved Office document, open the app and look under "Recover unsaved documents".
5. Use search to check that the file was not moved to another folder.

## Escalate if
The file was on a shared drive and is not in any recycle bin, it was deleted a long time ago, or it is business-critical. IT may be able to restore it from a backup, so give the file name, folder path and date.
