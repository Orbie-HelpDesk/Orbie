# Keyboard, Mouse and Monitor Problems

## Common problems
Keyboard not typing. Mouse not moving or clicking. Second monitor not detected. Screen is black or flickering. No signal on the monitor. External display shows the wrong size.

## When to use
A keyboard, mouse or monitor stops working or is not detected.

## Steps
1. Check that cables are firmly connected at both ends, and try another port.
2. For a wireless keyboard or mouse, replace the batteries and check the on switch or USB receiver.
3. For a monitor, check that it is powered on and set to the correct input (HDMI, DisplayPort or USB-C).
4. On the computer, press the Windows key and P to choose Extend or Duplicate for a second screen.
5. Restart the computer with the device connected.
6. Try the device on another computer to see if the device or the computer is at fault.

## Escalate if
The device fails on another computer too and needs replacing, a cable or dock looks damaged, or the laptop screen itself is black while the computer is on.
