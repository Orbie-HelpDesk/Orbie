# Multi-Factor Authentication (MFA) and Authenticator App

## Common problems
MFA code not working. Authenticator app shows wrong code. Got a new phone and lost my authenticator. Not receiving the verification code. Cannot sign in because of the second step. Need to set up MFA.

## When to use
Employee cannot complete the second sign-in step, or needs to set up or move the authenticator app to a new phone.

## Steps
1. Check that the phone's date and time are set to automatic. A wrong clock makes the codes fail.
2. Wait for the next code to appear in the app, then enter it before it expires.
3. To set up a new phone, sign in on a computer, open the security settings in the self-service portal and choose "Add authentication method".
4. Scan the QR code with the authenticator app on the new phone and confirm with the code shown.
5. Remove the old phone from the list of methods after the new one works.

## Escalate if
The old phone is lost and no other method is registered, the QR code page cannot be opened, or the account is locked after repeated failed codes.
